# Torah Scroll

A standalone, single-file tool — no build step, no dependencies on the
Task Manager app elsewhere in this repo. Open `index.html` directly in a
browser.

It shows the Ten Commandments (Exodus 20:2–11) as an open scroll, each
Hebrew letter drawn as an outline. Click any letter (or use "Ink next
letter") to fill it in, e.g. to mark a task done. Verse-number brackets
are printed for reference but aren't part of the click-to-fill count.
Progress is saved to the browser's local storage.

Planned: tie specific letters/verses to specific tasks, instead of a
free-standing click-any-letter tool.
